# 요구사항 (MVP)

## 가게 소개

- 가게 이름: 도화 (식물가게, 전북 전주)
- 판매: 식물(소·중·대), 축하화분(승진·개업·축하)
- 클래스: 원데이 클래스, 출강, 단체 수업
- 기존 문의 채널: 전화, 카카오톡 오픈채팅, 인스타그램 DM
- 운영: 사장님이 상품·문의를 직접 관리 (비개발자)

## 페이지

| 페이지 | 내용 |
|---|---|
| 홈 | 가게 소개, 대표 사진, 주요 메뉴 바로가기 |
| 식물 | 소·중·대 크기별 상품 목록 (사진, 이름, 가격, 배송 방식) |
| 축하화분 | 승진·개업·축하 용도별 상품 목록 |
| 클래스 | 클래스 종류와 가격, 출강·단체 수업 안내 |
| 문의하기 | 주문·클래스·단체 문의 폼 |
| 오시는 길 | 지도, 영업시간, 연락 채널 버튼 |

모든 페이지에 전화·카카오톡·인스타그램 버튼을 고정한다.

## 기능

### 주문 문의 (결제 없음)
- 상품, 수량, 배송 방식, 받는 날짜, 배송지, 리본 문구, 이름, 연락처, 개인정보 수집 동의
- 예상 배송비를 자동으로 보여준다.

### 배송 규칙
| 배송 방식 | 대상 | 지역 | 배송비 |
|---|---|---|---|
| 택배 | 소형 식물, 인테리어 오브제, 소품 | 전국 | 4,000원 |
| 직접 배달 | 중·대형 식물 등 | 전주 한정 | 80,000원 미만 5,000원, 80,000원 이상 무료 |

- 배송비와 기준 금액은 코드에 고정하지 않고 설정값으로 관리한다.
- 직접 배달 상품의 배송지가 전주가 아니면 안내 문구를 보여준다.

### 클래스 예약 문의
| 클래스 | 1인 가격 |
|---|---|
| 화분 꾸미기 & 가드닝 원데이 클래스 | 30,000원 |
| 수형 잡기 원데이 클래스 | 35,000원 |
| 크리스마스 생화 리스 만들기 (시즌) | 40,000원 |

- 인원 1~4명, 소요 시간 60~90분
- 인원을 고르면 금액을 자동으로 계산한다.
- 5명 이상, 단체 수업, 출강은 별도 문의 폼 (기관명, 인원, 장소, 희망 날짜)
- 시즌 클래스는 관리 화면에서 열고 닫을 수 있다.
- 일정은 희망 날짜를 입력받고 사장님이 연락해 확정한다.

### 사장님용 관리 화면 (모바일)
- 비밀번호 로그인 (회원 시스템 아님)
- 상품·클래스 등록, 수정, 품절·숨김 처리, 사진 업로드
- 문의 목록, 처리 상태 변경 (접수 → 연락함 → 완료)
- 새 문의 알림 (텔레그램)

### 운영자용 관리 (SQLAdmin)
- 전체 데이터와 설정값 관리, SSM 포트 포워딩으로만 접속

## 비기능 요구사항
- 모바일 우선 화면
- 문의 폼 스팸 방지 (요청 수 제한, 허니팟)
- 처리 완료된 문의의 개인정보는 일정 기간 후 자동 삭제
- 데이터 손실 허용 범위(RPO) 24시간, 복구 목표 시간(RTO) 1시간

## MVP 제외
결제, 회원가입, 장바구니, 리뷰, 재고 관리
