# 요구사항 (MVP)

> 2026-11-20 방향 전환: 홈페이지는 주문을 처리하지 않고, **새 손님 유입과 출강·단체 수업 확대**를 목표로 한다. (ADR 0012)

## 가게 현황

- 가게 이름: 도화 (식물가게, 전북 전주)
- 판매: 식물(소·중·대), 축하화분(승진·개업·축하) — 스마트스토어 운영 중, 주문은 적음
- 클래스: 원데이 클래스, 출강·단체 수업 (월 1~2건)
- 연락 채널: 전화, 카카오톡 오픈채팅, 인스타그램 DM
- 운영: 사장님이 콘텐츠와 문의를 직접 관리 (비개발자)

## 목표와 성공 지표

| 목표 | 지표 | 현재 |
|---|---|---|
| 출강·단체 수업 늘리기 | 월 출강·단체 문의 수 | 1~2건 |
| 새 손님 유입 | 검색 유입 수, 방문 수 | 측정 안 함 |
| 구매 고객·선물 받은 사람 재방문 | QR 스캔 수 | 없음 |
| 어디서 왔는지 파악 | 문의별 유입 경로 | 측정 안 함 |

## 대상 고객

| 고객 | 원하는 것 | 홈페이지가 주는 것 |
|---|---|---|
| 기관 담당자 (학교, 어린이집, 복지관, 주민센터, 기업) | 믿을 만한 업체인지, 기안에 첨부할 자료, 견적 | 진행 사례, 대상별 프로그램, 소개서 PDF, 견적 문의 폼 |
| 화분을 산 사람, 선물 받은 사람 | 식물을 죽이지 않고 키우는 법 | QR 카드 → 식물 관리 가이드 |
| 검색하는 일반 손님 | 가게 분위기, 클래스, 위치 | 작품 갤러리, 클래스 소개, 연락 버튼 |

## 페이지

| 페이지 | 경로 | 내용 |
|---|---|---|
| 홈 | `/` | 가게 소개, 출강 안내 배너, 대표 작품, 연락 버튼 |
| 클래스·출강 | `/classes` | 클래스 종류와 가격, 출강·단체 수업 안내, 대상별 프로그램 |
| 진행 사례 | `/cases`, `/cases/{id}` | 출강·단체 수업 사례 (사진, 기관 유형, 인원, 프로그램) |
| 견적 문의 | `/outreach` | 출강·단체·기업 문의 폼, 소개서 PDF 다운로드 |
| 식물 가이드 | `/guides`, `/guides/{slug}` | 식물별 관리법 (빛, 물, 온도, 습도, 계절별 관리, 문제 해결) |
| 작품 갤러리 | `/gallery` | 대표 작품 사진, 스마트스토어 링크 |
| 오시는 길 | `/visit` | 지도, 영업시간, 연락 채널 |
| 링크 모음 | `/links` | 인스타그램 프로필용. 스마트스토어, 카카오톡, 전화, 출강 문의 버튼 |
| QR 연결 | `/q/{code}` | 스캔 기록 후 식물 가이드로 이동 (화면 없음) |

모든 페이지에 전화·카카오톡·인스타그램 버튼을 고정한다.

## 기능

### 출강·단체 견적 문의 (핵심)
| 항목 | 필수 | 비고 |
|---|---|---|
| 문의 종류 | O | 출강 / 매장 단체 수업 / 기업 화분 대량 주문 / 기타 |
| 기관명 | O | |
| 기관 유형 | O | 학교, 어린이집·유치원, 복지관, 주민센터·공공기관, 기업, 기타 |
| 담당자 이름, 연락처 | O | **개인정보** |
| 이메일 | | 견적서·소개서 회신용 |
| 인원 | O | |
| 대상 | | 어린이, 청소년, 성인, 시니어 |
| 희망 일정 | O | 자유 입력 ("12월 둘째 주 평일 오후") |
| 장소 | | 출강일 때 |
| 관심 클래스 | | 선택 |
| 예산 범위 | | 선택 |
| 알게 된 경로 | O | 검색, 인스타그램, QR 카드, 지인 소개, 기존 고객, 기타 |
| 요청사항 | | |
| 개인정보 수집 동의 | O | |

- 접수되면 사장님 텔레그램으로 알림.
- 유입 경로는 손님이 고른 값과 함께, 페이지가 자동으로 기록한 값(첫 방문 경로, UTM)도 저장한다.

### 진행 사례
- 사진, 기관 유형, 인원, 진행한 클래스, 짧은 후기.
- 기관 이름은 기관 동의가 있을 때만 공개한다 (기본: "전주 ○○초등학교"처럼 가림).

### 식물 관리 가이드와 QR 카드
- 가이드 항목: 이름, 학명, 난이도, 빛, 물 주기, 온도, 습도, 계절별 관리, 자주 생기는 문제와 해결법, 사진.
- QR 주소는 `/q/{짧은 코드}`. 코드가 가리키는 가이드는 관리 화면에서 바꿀 수 있다 (ADR 0013).
- 관리 화면에서 QR 이미지(PNG, SVG)를 내려받아 카드로 인쇄한다.
- 가이드 페이지 하단: "이 식물은 도화에서 왔어요" + 클래스·출강 안내 + 연락 버튼.

### 작품 갤러리
- 사진, 제목, 짧은 설명, 스마트스토어 링크(선택).
- 상품 재고·가격은 관리하지 않는다 (스마트스토어가 기준).

### 클래스 소개
| 클래스 | 1인 가격 |
|---|---|
| 화분 꾸미기 & 가드닝 원데이 클래스 | 30,000원 |
| 수형 잡기 원데이 클래스 | 35,000원 |
| 크리스마스 생화 리스 만들기 (시즌) | 40,000원 |

- 매장 개인 수업: 1~4명, 60~90분. 예약은 카카오톡으로 연결.
- 5명 이상, 단체, 출강: 견적 문의 폼으로 연결.
- 시즌 클래스는 관리 화면에서 열고 닫는다.

### 사장님용 관리 화면 (모바일)
- 비밀번호 로그인 (회원 시스템 아님)
- 문의 확인, 상태 변경, 메모
- 진행 사례, 작품 갤러리, 식물 가이드, 클래스 등록·수정 (사진 업로드 포함)
- QR 코드 발급, 연결 가이드 변경, 이미지 내려받기
- 첫 화면 요약: 새 문의 수, 이번 달 QR 스캔 수

### 운영자용
- SQLAdmin: 전체 데이터, 설정값 관리
- Grafana: 서버 지표 + 비즈니스 지표 (문의 수, 유입 경로별 문의, QR 스캔 수)
- Umami: 방문 분석
- 모두 SSM 포트 포워딩으로만 접속

## 비기능 요구사항
- 모바일 우선 화면
- 검색 노출: 페이지별 제목·설명 메타 태그, sitemap.xml, 구글 서치 콘솔과 네이버 서치어드바이저 등록
- 문의 폼 스팸 방지 (요청 수 제한, 허니팟)
- 처리 완료된 문의의 개인정보는 일정 기간 후 자동 삭제
- 인쇄된 QR 주소(`/q/*`)는 서비스가 존재하는 한 동작해야 한다
- 데이터 손실 허용 범위(RPO) 24시간, 복구 목표 시간(RTO) 1시간

## MVP 제외
결제, 회원가입, 장바구니, 온라인 주문·예약, 상품 재고·가격 관리, 배송비 계산
