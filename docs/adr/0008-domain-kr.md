# 0008. .kr 도메인, 사장님 명의, Route 53 위임

- 상태: 대체됨 (ADR 0009)
- 날짜: 2026-11-19

## 결정
- `.kr` 영문 도메인을 사용한다. 한글 도메인은 쓰지 않는다.
- 국내 등록 업체에서 사장님 명의로 등록한다.
- 네임서버를 Route 53 호스팅 영역으로 위임한다.

## 이유
- 한국 동네 가게에 어울린다. 비용은 `.com`과 비슷하다.
- 도메인은 가게의 자산이므로 사장님이 소유해야 운영자가 바뀌어도 문제가 없다.
- Route 53은 `.kr` 등록을 지원하지 않으므로 네임서버 위임으로 DNS를 관리한다.
- 한글 도메인은 공유할 때 주소가 `xn--` 형식으로 보일 수 있다.
