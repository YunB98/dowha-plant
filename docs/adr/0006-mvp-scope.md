# 0006. MVP에서 결제·회원 기능 제외

- 상태: 일부 대체됨 (ADR 0012) — 결제·회원 제외는 유지
- 날짜: 2026-11-19

## 결정
MVP에서는 결제, 회원가입, 장바구니, 리뷰, 재고 관리를 만들지 않는다. 주문과 클래스 예약은 문의로 접수하고 사장님이 연락해 확정한다.

## 이유
- 결제와 회원 정보는 보안과 개인정보 부담이 크다.
- 도화는 이미 전화, 카카오톡, 인스타그램으로 주문을 받고 있다.
- 사이트를 가볍게 유지하고 인프라와 운영에 집중한다.

## 결과
- 문의 폼에서 이름과 연락처는 수집한다. 개인정보 수집 동의를 받고, 처리 완료된 문의의 개인정보는 일정 기간 후 자동 삭제한다.
