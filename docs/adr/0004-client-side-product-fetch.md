# 0004. 상품 목록은 브라우저에서 API로 조회

- 상태: 채택
- 날짜: 2026-11-19

## 배경
Next.js 정적 빌드는 빌드할 때 페이지를 만든다. 그래서 사장님이 상품을 등록해도 다시 빌드하기 전까지 사이트에 나타나지 않는다.

## 결정
페이지 틀은 정적으로 배포하고, 상품·클래스 목록은 브라우저에서 API로 불러온다.

## 이유
- 사장님이 등록하면 바로 반영된다.
- 구조가 가장 단순하다.
- 동네 가게는 상품 페이지보다 네이버 플레이스로 검색되는 경우가 많아 검색 노출 손해가 작다.

## 대안
- 저장하면 GitHub Actions로 자동 재빌드: v2에서 추가한다.
- 서버에서 페이지 그리기(SSR): 서버 한 대 구성에서 메모리 부담이 커서 제외한다.
