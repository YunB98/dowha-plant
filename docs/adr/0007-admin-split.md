# 0007. 관리 화면을 사장님용과 운영자용으로 분리

- 상태: 채택
- 날짜: 2026-11-19

## 배경
사장님은 개발자가 아니지만 상품과 문의를 직접 관리한다. 운영자(개발자)는 서버와 데이터 전체를 관리한다.

## 결정
| 대상 | 도구 | 기능 |
|---|---|---|
| 사장님 | Next.js 모바일 관리 화면 | 상품·클래스 등록과 수정, 품절·숨김, 사진 업로드, 문의 처리 |
| 운영자 | SQLAdmin | 전체 데이터, 설정값 관리. SSM 포트 포워딩으로만 접속 |

## 이유
- 상품은 자주 바뀐다. 사장님이 직접 수정하지 못하면 운영자에게 의존하게 되고 사이트 운영이 멈춘다.
- SQLAdmin은 개발자용 화면이라 비개발자가 쓰기 어렵다.

## 결과
- 사장님용 화면은 자주 쓰는 3~4개 기능만 넣고 휴대폰에서 쓰기 편하게 만든다.
- 운영 책임: 사장님은 콘텐츠, 운영자는 서버·배포·백업·보안·도메인을 맡는다.
